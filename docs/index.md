# CookieCraft Wiki

This is the wiki for the [CookieCraft](https://modrinth.com/modpack/cookiecraft) Minecraft modpack!

CookieCraft is a modpack with the goal of improving the player's experience without too many mods.
It aims to be lightweight but still have all the features you need.

This wiki has two main sections.
The first section is for users;
this is what you want if plan on using the pack without making any changes.
The other section is for modpack creators;
people who want to use the pack as a starting off point for their own pack.
The wiki also includes information on how you can contribute to the pack in the about section.
