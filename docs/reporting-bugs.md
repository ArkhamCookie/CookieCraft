# How to Report Bugs

To report bugs,
please use the [issue tracker](https://github.com/ArkhamCookie/CookieCraft/issues).
First search to see if the bug has been reported already.
If it hasn't been reported yet,
open an issue with the bug tag. [^1]

[1]: Issue templates will soon make this easier, but I need to make them first.  See [this issue](https://github.com/ArkhamCookie/CookieCraft/issues/64) if you want to help.
