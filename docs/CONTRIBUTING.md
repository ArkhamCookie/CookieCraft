# Contributing

Information on how you can help contribute to CookieCraft.

## Setup Your Environment

### Using Nix (Recommended)

For this repo we use [Nix](https://en.wikipedia.org/wiki/Nix_(package_manager)) to make tooling easy.
All you have to do is [install Nix](https://nixos.org/download/) and run `nix-shell` in the project directory to have all the tools required for this repo working.

### Not Using Nix (Not Recommended)

If you choose to not use Nix,
you will have to install all the dev tools manually.

Currently this project uses these tools:

- [just](https://just.systems)
- [mkdocs](https://www.mkdocs.org/)
- [packwiz](https://packwiz.infra.link/)

## Documentation

This project uses [mkdocs](https:/www.mkdocs.org/) to build the wiki.
This means that you can just edit the documentation using [Markdown](https://en.wikipedia.org/wiki/Markdown).
Once you make your chanages,
you can preview the changes by running `just serve-docs` and going to <http://127.0.0.1:8000>.

## Code

This project uses very little code.
It is mainly the documentation, config files, and tools to make those things easier.
The main area you help help by coding is the things like the workflows and just scripts.
If you see any issues with them,
or you think there is a way to improve them,
feel free to open up an issue on [our bug tracker](https://github.com/ArkhamCookie/CookieCraft/issues) to discuss it.
